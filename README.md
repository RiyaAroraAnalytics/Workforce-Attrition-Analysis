# Workforce-Attrition-Analysis
Exploratory Data Analysis (EDA) and predictive modeling of employee attrition patterns to support workforce retention and organizational growth.
##  Project Overview
This project analyzes HR data to identify key factors driving employee attrition. The goal is to uncover patterns and insights that help organizations reduce turnover and improve retention strategies.

##  Tools & Technologies
- *Excel* – Data cleaning and classification
- *Tableau* – Interactive dashboards and visualizations
- *Python* – Data processing and analysis

##  Key Areas of Analysis
- Employee attrition rate by department, age, and job role
- Salary and satisfaction impact on turnover
- Predictive indicators of at-risk employees

## Dataset
HR Employee Attrition Dataset (IBM HR Analytics)
